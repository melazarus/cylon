Cylon LED control

Set the three WS2812 LEDs over USB-MIDI (Web MIDI API).

Not connected.
Protocol: F0 13 37 <led> <r> <g> <b> F7, where <led> is 0x00 for all LEDs or 0x01/0x02/0x03 for one LED. Each channel is sent as a 7-bit value, so the LED always receives an even 8-bit value (the “effective” colour shown under each picker). Web MIDI needs a secure context: if the browser blocks it from file://, serve this folder with python -m http.server and open http://localhost:8000/set_leds.html.
